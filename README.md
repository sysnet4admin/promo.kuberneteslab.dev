# promo.kuberneteslab.dev

리눅스 재단 자격증 할인 코드 안내 페이지입니다. 상시 할인 코드, 지금 진행 중인
프로모션, 2021년 10월부터 쌓아 온 할인 이력을 한국어와 영어로 보여줍니다.

Hugo로 만든 단일 페이지 사이트이고 Cloudflare Pages에 배포합니다.

## 구조

| 경로 | 내용 |
|---|---|
| `content/{ko,en}/_index.md` | 페이지 본문 |
| `data/promo/history.yaml` | 프로모션 이력과 CKA 정가 이력 |
| `layouts/shortcodes/` | 현재 프로모션 배너, 비교 문장, 요약 차트, 이력 표 |
| `assets/css/main.css` | 전체 스타일 (라이트, 다크) |
| `static/_redirects` | 제휴 링크 리다이렉트 |

프로모션이 새로 나오면 `data/promo/history.yaml`에만 추가하면 됩니다. 배너와 차트,
이력 표가 모두 이 파일을 읽습니다. 기간이 지난 프로모션은 빌드 시점 선택과
브라우저 쪽 만료 처리로 자동으로 내려갑니다.

## 로컬 실행

```bash
hugo server
```

한국어는 `/`, 영어는 `/en/`에서 뜹니다.

## 배포

`main`에 푸시하면 GitHub Actions가 빌드해서 Cloudflare Pages로 올립니다. 진행
중인 프로모션이 기간을 넘겼을 때 화면이 따라가도록 매일 한 번 다시 배포합니다.

## 제휴 링크 고지

이 페이지의 링크로 결제하면 판매 금액의 일부가 제휴 수수료로 지급됩니다. 수수료는
리눅스 재단이 부담하므로 구매자가 내는 금액은 달라지지 않습니다.
